# Dashboard

## Purpose

The dashboard layer presents the main findings of the Credit Policy Experiment in a concise, decision-oriented format.

The analytical work is performed in the Python notebooks. The dashboard is intended to communicate the resulting experiment, risk, and economic metrics rather than reproduce the underlying statistical calculations.

## Planned Dashboard

The primary dashboard will be developed in **Microsoft Power BI**.

It will focus on three areas:

### 1. Executive Decision

Key policy metrics:

- Control vs Treatment default rate
- Control vs Treatment approval rate
- Absolute default-rate reduction
- Approval-rate reduction
- Expected loss under each policy
- Modeled expected-loss savings
- Additional rejections
- Break-even contribution per additional rejection

### 2. Risk Analysis

The risk section will present:

- Risk-decile performance
- Predicted PD vs observed default rate
- Default rate by loan grade
- DTI-based risk segmentation
- Income-based risk segmentation
- Loan-size segmentation

### 3. Experiment & Statistical Evidence

The statistical section will present:

- Treatment effect
- 95% confidence interval
- Z-statistic
- p-value
- Experiment population
- Required sample size
- Statistical power
- Minimum detectable effect

## Data Source

The dashboard will use outputs generated by the project analysis pipeline.

The underlying analytical workflow is:

```text
01 Data / Experiment Construction
              ↓
02 Exploratory Data Analysis
              ↓
03 Hypothesis Testing
              ↓
04 Power Analysis
              ↓
05 Logistic Regression
              ↓
06 Expected Loss
              ↓
       Power BI Dashboard
```

## Key Principles

The dashboard will:

- Prioritize decision-relevant metrics.
- Distinguish statistical results from economic assumptions.
- Clearly identify modeled values.
- Avoid presenting expected-loss savings as realized profit.
- Make LGD assumptions and EAD methodology visible.
- Keep the dashboard focused rather than adding unnecessary visualizations.

## Current Status

The dashboard directory currently contains the documentation for the planned Power BI layer.

The Power BI dashboard will be added after the analytical notebooks and dashboard data requirements are finalized.
